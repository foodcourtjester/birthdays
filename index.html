PWA Bundle & Deployment Guide

This application is completely self-contained in a single HTML file using Blob-injected Service Workers and Web Manifests. If you wish to host it on a server (e.g. GitHub Pages or Vercel), you can separate the files below:

1. manifest.json 
{
  "name": "Celebration Tracker PWA",
  "short_name": "Celebrations",
  "start_url": "./",
  "display": "standalone",
  "background_color": "#f8fafc",
  "theme_color": "#db2777",
  "icons": [{ "src": "icon.png", "sizes": "512x512", "type": "image/png" }]
}
2. sw.js (Service Worker) 
const CACHE_NAME = 'celeb-tracker-v2';
self.addEventListener('install', (e) => self.skipWaiting());
self.addEventListener('activate', (e) => self.clients.claim());
self.addEventListener('fetch', (e) => {
  e.respondWith(fetch(e.request).catch(() => caches.match(e.request)));
});

How Live CSV Sync Works:

When you click "Open CSV", the app requests direct access to your local reminders.csv file. A background timer automatically monitors the file every 10 seconds (and when switching browser tabs). Any changes made directly in Excel or Notepad automatically update the dashboard display!
